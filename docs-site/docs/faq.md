# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 云端网关能直接访问我本机的内网文件吗？

**A**: 不能。云端网关仅负责反向代理与身份令牌核验，任何实际操作均由部署在本地的 Bridge 客户端发起反向长连接拉取，外网无法主动向内网穿透。

### Q: 为什么有些简单命令执行也会触发弹窗？

**A**: 默认安全策略下，所有涉及本地文件覆盖、全局环境变量读取与未经白名单登记的 Shell 指令均属于高危范围，必须经过本地物理确认。

### Q: 容器执行结束后数据会残留吗？

**A**: 隔离容器在任务退出后会连同临时文件卷自动执行强制销毁与回收，确保任务间互不污染。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
