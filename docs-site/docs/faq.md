# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 云端网关能直接访问我本机的内网文件吗？

**A**: 云端网关通过本机连接器主动建立的 WebSocket 连接转发请求。文件操作在本机批准后交给容器执行；云端中继能看到经过它的工具输入输出，因此属于信任边界的一部分。

### Q: 为什么简单命令也需要本机批准？

**A**: 读取、列目录、搜索、修改文件和执行命令都需要精确批准。客户端收到 `LOCAL_APPROVAL_REQUIRED` 后，在本机通过可信 `Approve.cmd` 核对参数并批准，再用相同参数重试。批准在 5 分钟内有效且只能使用一次。

### Q: 容器执行结束后数据会残留吗？

**A**: 工程目录以读写方式挂载，写入其中的文件会保留。容器的临时 HOME 和临时目录随容器销毁；若返回 `cleanup_confirmed: false`，说明清理未确认，应在本机检查 Docker。连接器此时拒绝新的命令和文件操作，已有任务仍可查询或停止。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
